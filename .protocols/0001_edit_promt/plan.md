# План изменения prompt для summary

## Контекст

Текущий prompt для `create_summary` делает не просто краткую новостную сводку, а скорее стратегический briefing. В нём смешаны несколько целей сразу: пересказ фактов, аналитика, объяснение значимости, рекомендации к действиям и форматирование под Telegram.

## Почему меняем prompt

1. **Слишком сложная задача для одного prompt**  
   Текущая версия одновременно просит факты, контекст, стратегическую интерпретацию и действия. Из-за этого ответы могут получаться перегруженными.

2. **Лишняя аналитичность**  
   Prompt делает упор на strategic briefing, хотя целевая задача ближе к короткому и понятному summary.

3. **Ненужный блок "Действия"**  
   Он подталкивает модель придумывать рекомендации даже там, где достаточно просто кратко и ясно пересказать новость.

4. **Смешение языков**  
   Инструкции написаны в основном на английском, а результат ожидается на русском. Это может делать стиль менее ровным.

5. **Размытая аудитория**  
   Упоминание бизнесменов, программистов и IT-специалистов делает prompt менее точным и уводит тон в разные стороны.

## На какой prompt меняем

Новый prompt должен быть:

- полностью **на русском языке**;
- без упоминания конкретных ролей и аудиторий;
- ориентирован на **краткий новостной дайджест**;
- сфокусирован на ответе на два вопроса:
  - **что произошло**;
  - **почему это важно**;
- без блока **«Действия»**;
- с упором на **конкретику**: компании, продукты, релизы, исследования, цифры, даты;
- в формате **3–5 главных новостей**;
- в чистом Telegram-friendly HTML: только `<b>` и `<i>`.

## Черновая концепция нового prompt

Новая версия prompt должна просить модель:

1. Выбрать 3–5 самых важных новостей из переданного контента.
2. Для каждой новости кратко и понятно описать:
   - что произошло;
   - почему это важно.
3. Не уходить в лишнюю аналитику, прогнозы и рекомендации.
4. Сохранять конкретные названия компаний, моделей, продуктов и численные детали.
5. Выдавать результат в коротком, аккуратном формате для Telegram.

## Черновик целевого prompt

```text
Сделай краткую новостную сводку по материалам TLDR AI за {date}.

Пиши на русском языке.

Задача:
- выбрать 3–5 самых важных новостей;
- для каждой новости кратко объяснить:
  - что произошло;
  - почему это важно.

Требования:
- сохраняй конкретику: названия компаний, продуктов, моделей, исследований, даты, цифры и ключевые факты;
- не превращай новости в абстрактные рассуждения;
- не добавляй блок с действиями, советами или рекомендациями;
- не раздувай текст лишним контекстом;
- пиши кратко, ясно и по делу.

Формат:
- начни с заголовка: <b>📰 AI News Briefing - {date}</b>
- используй только теги <b> и <i>
- не используй другие HTML-теги
- выделяй каждую новость как отдельный блок
- делай двойной перенос строки между блоками
- общий объём — до 600–800 слов

Структура каждой новости:
<b>🔹 [Заголовок с названием компании / продукта]</b>
<b>Что произошло:</b> ...
<b>Почему это важно:</b> ...

Материалы рассылки:
{content}
```
